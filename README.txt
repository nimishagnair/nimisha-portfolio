PORTFOLIO SETUP

1. Open index.html locally to preview. The portfolio images are embedded in the HTML, so they will display even if you only open the HTML file.
2. For GitHub Pages, upload ALL files in this folder to the ROOT of your repository (not inside another folder). Keep WELoRaD-Lung-Cancer-Research-Paper.pdf beside index.html so the PDF link works.
3. In GitHub Settings > Pages, select Deploy from a branch, branch main, folder /(root), then Save.
4. This version does not display your phone number.
